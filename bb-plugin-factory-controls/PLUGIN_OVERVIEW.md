## Set each factory step

Choose a shared provider, model, and effort. Override planning, building,
repair, review, and revision when they need different choices. The Factory
panel shows the resolved choice beside each step and saves each change.

## Open the controls

In a Software Factory task, open the right panel. Select **New tab**, then
**Factory**. Set your choices before sending the work request.

This version supports workspaces on the BB server machine. It requires the
Software Factory Python command and its registered ACP agent. The existing
factory execution protection remains in force.
